## Project Memory Protocol (PMP 0.2.1)

Canonical operational memory lives at the repository-root `PROJECT_MEMORY.md`.

Before significant work, read that file and revalidate task-critical repository or external state. Do not treat `[DOCUMENTED]` or `[ASSUMED]` claims as current evidence.

For bounded work, preserve allowed scope and consequential exclusions. Record
adjacent findings without treating discovery as permission to remediate them.

If the session changes current state, decisions, constraints, priorities, or the next action, update canonical memory before handoff. Keep history in `.project-memory/sessions/YYYY-MM-DD-topic.md` when useful. Do not write secrets, credentials, `.env` values, or unnecessary personal data.

Precedence: latest authorized human instruction -> current verified evidence -> canonical memory -> specialized documentation -> session history -> private model memory. Verify or escalate same-level conflicts instead of guessing.

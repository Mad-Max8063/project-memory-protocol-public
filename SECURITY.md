# Security policy

PMP is a documentation protocol with dependency-free Python validators. Please
report vulnerabilities through GitHub private vulnerability reporting when it
is available for this repository.

If private reporting is unavailable, contact the maintainer through the GitHub
profile rather than publishing credentials, exploit details, private project
data, or other sensitive evidence in a public issue.

Never include real secrets in test cases or reproduction repositories. Use
clearly synthetic placeholders and remove private identifiers before sharing.

# Contributing

Thanks for helping improve Project Memory Protocol.

Before proposing a change:

1. Read [SPEC.md](SPEC.md) and the evidence boundaries in [README.md](README.md).
2. Keep the baseline protocol vendor-neutral and dependency-free.
3. Add or update deterministic tests for validator behavior.
4. Run the full verification workflow locally.
5. Avoid credentials, private repository references, personal data, and
   unverifiable claims in commits, issues, or examples.

Small, focused pull requests are preferred. Behavioral protocol changes should
describe compatibility impact and must not be presented as a patch-level
metadata correction.

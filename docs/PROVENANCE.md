# Clean distribution provenance

This repository is a clean, self-contained distribution of Project Memory
Protocol Core `0.2.1` and the optional Evidence-backed Handoff profile `0.1.1`.

The distribution preserves the protocol specification, reusable templates,
adapters, validators, tests, and reproducible packaged handoff example. It does
not reproduce the private operational Git history used while developing and
reviewing the protocol.

Excluded material includes private product or pilot identifiers, internal
release-planning documents, operational session logs, private CI references,
and evidence from unrelated repositories. Their exclusion is a privacy and
distribution boundary; it is not a claim that the protocol was developed
without prior experiments or review.

The canonical public claim remains narrow: PMP preserves explicit operational
project state through versioned repository context. It does not synchronize
hidden model memory, prove agent identity, or prove session freshness.
